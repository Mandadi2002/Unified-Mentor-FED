About This Project

“Vikram and Betal” is an interactive storytelling experience designed for Solving riddles and puzzles for raised questions by a ghost betal.

The project aims is The Vikram and Betal stories are not just entertaining—they're packed with wisdom, morals, and life lessons to teach while immersing users in a dynamic and responsive journey. It’s built using HTML, CSS, and JavaScript, with plans for future stories to be added to this collection.

Created by Rohit Reddy Mandadi as part of a Frontend Development.

🌿 Cover Page: Vikram and Betal
The Vikram and Betal stories are a collection of ancient Indian tales that combine mystery, morality, wit and solving riddles and puzzles.
